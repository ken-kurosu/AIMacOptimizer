# build16 LP・配布整合ハンドオフ

確認日: 2026-07-27  
対象LP: `aimacoptimizer/aimacoptimizer.github.io` の `index.html`  
対象アプリ: build16（2.1.13）

## 課金境界の正本

- Free: メモリ最適化、タブ分析、詳細診断、ローカル/オンデバイスAI相談、ストレージ分析とユーザー承認による手動整理、多言語。
- Pro: スケジュール自動最適化、自動ディスクガード、履歴・トレンド、詳細な週次レポート。
- 「優先サポート」は専用経路/SLAが実装されていないため販売訴求しない。

## LPでbuild16公開前に直す箇所

行番号は確認時の `index.html`。同じ文言が日本語・英語・中国語の辞書にもあるため、3言語を同時に直す。

1. `softwareVersion`（64行）を、build16公開と同時に `2.1.13` へ更新する。
2. DMGリンク（312、380、406行）に残る固定版 `releases/download/v2.0.0/...` を、すべて次へ置換する。
   `https://github.com/ken-kurosu/AIMacOptimizer/releases/latest/download/AIMacOptimizer-latest.dmg`
3. Pro項目（325、338、457、532、607行付近）から、Freeにも含まれる「AIで原因を深掘り・相談」を削除する。
4. 同じPro項目から、運用上の裏付けがない「優先サポート」を削除する。
5. FAQ/JSON-LD（78、368、474、549、624行付近）のPro追加機能を、
   「スケジュール自動最適化、自動ディスクガード、履歴・トレンド、詳細な週次レポート」へ直す。
6. 「削除はすべてゴミ箱経由」（81、249、255、368、423、441、477行付近と翻訳）を、次の事実に沿う表現へ直す。
   「個人ファイルとアプリはゴミ箱へ移動。再生成できるキャッシュ/ログ/一時ファイルは、対象・復元不可を表示し、明示選択後に直接削除します。」
7. 「外部送信0件」「データは一切外へ出ない」（80、267〜270、423、443〜445行付近と翻訳）を、次へ直す。
   「ファイル内容と診断結果はローカルで処理します。匿名の操作統計は初期OFFで、設定から同意した場合だけ送信します。ライセンス確認と更新確認には通信を使います。」
8. 安全性モックはキャッシュ削除をゴミ箱移動と誤認させるため、ゴミ箱へ移す個人ファイルの例にするか、「直接削除・復元不可」の例として明示する。

## 公開順序

1. build16の署名・公証・stapleを完了する。
2. GitHub Releaseへ `AIMacOptimizer-latest.dmg` と、build16を示す `latest.json` を同時にアップロードする。
3. `/releases/latest/download/...` がbuild16を返すことを確認する。
4. 上記LP修正をpushし、3言語表示、構造化データ、ダウンロードリンクを確認する。

LPだけを先に `2.1.13` 表示へ変えると、表示と配布物が再び食い違うため、必ずこの順序で行う。
